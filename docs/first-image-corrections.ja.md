# 初回生成イメージを検査して修正した内容

run `37329795720` はAndroid 10のsystem imageを生成した。
ビルド記録と圧縮・展開後のSHA-256は照合済みだが、実機導入には進めない状態だった。

- 展開容量は1,766,428,672 bytesで、実測system容量1,413,480,448 bytesを超えた。
- `build.prop`にはPHH側の`ro.adb.secure=1`に加え、GSI側の`ro.adb.secure=0`が含まれた。
- `ro.product.locale`は`en-US`だった。継承したAOSPの言語リストが先に入った。

修正では、固定コミットとGit blobを確認した入力だけを変更する。
GSI側のADB認証無効化行を削除し、既存の認証付きADB設定を保持する。
日本語・英語の順序と追加VNDKバージョンを、継承後のルートproductで指定する。
PHHの32/64ビットVNDK 26・27コピーを外し、実機vendorが使う28と現行29を残す。
system imageの上限を実測値に固定し、内部に32MiBの空きを要求する。
サイズに収まらなければビルドを失敗させ、容量超過を検査対象から外さない。

元入力のバックアップ、再適用時の無変更判定、未確認の入力を拒否する処理を維持する。
これらの修正で収まるか、初期言語とADB設定が意図どおりかは、次の生成物で検査する。
ソースの検査成功だけでは起動、タッチ、Wi-Fi、AVB、復旧手順の検証完了とはしない。
